# ⚽ FIFA World Cup (1930 - 2014) Power BI Dashboard

This Power BI project provides an in-depth, interactive analysis of the **FIFA World Cup tournaments from 1930 to 2014**. The dashboard captures the historical journey of the tournament using visuals, KPIs, and performance metrics related to teams, players, matches, and global insights.

---

## 📁 Dashboard Pages Overview

### 1. 🏆 Tournament Overview
- High-level KPIs showing number of tournaments, total matches, goals scored, and average attendance.
- Timeline of host countries and champions across all editions from 1930 to 2014.

### 2. 📊 Match Statistics
- Visual breakdown of goals scored, match stages, and winning conditions.
- Comparative insights on home vs away performances and referee involvement.

### 3. 🌍 Map View
- Interactive map showcasing host countries and key cities.
- Geo-distribution of tournaments with tooltips for match and attendance stats.

### 4. 🧍‍♂️ Player Analysis
- Player statistics across all World Cups.
- Includes shirt numbers, player names, match appearances, and team initials.
- Drill-down features for deeper player-level insights.

### 5. 💡 Insights
- Aggregated highlights such as top-scoring teams, most appearances, and recurring finalists.
- Comparative visuals on attendance trends, match outcomes, and performance evolution.

---

## 🗃️ Dataset Description (Kaggle)

Data was pre-processed and joined using Power BI’s modeling features and DAX measures.

---


## 📌 Key Features

- Clean page navigation for smooth transitions.
- Advanced DAX calculations for aggregations and rankings.
- Historical timeline analysis and KPIs.
- Slicers and filters for Year, Stage, Teams, and Players.
- Map visuals for global engagement analysis.

## 🚀 How to Use

1. Open the `.pbix` file in **Power BI Desktop**.
2. Refresh the data if needed.
3. Use slicers and page navigation buttons to interact with visuals.
4. Explore historical trends and player-level stats dynamically.
